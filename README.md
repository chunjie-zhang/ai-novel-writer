# AI 小说创作工具 ✍️

一款专为网文作者、长篇创作者打造的**桌面端 AI 创作助手**，对标 FeelFish。所有稿件、人设、世界观都保存在你自己电脑上——隐私安全、离线可用。

## ✨ 核心特性

- 🗂️ **本地项目化管理** — 每本小说一个项目，章节/角色/世界观/大纲/伏笔全部**按项目隔离**，互不串数据
- 📝 **Markdown 所见即所得编辑器** — Milkdown 渲染，**自动保存**、断稿记忆防丢失、改标题自动同步左侧目录
- 🤖 **32 个写作技能** — 世界观 / 角色 / 剧情 / 写作 / 审校 / 翻译 / 工具六大类，一键唤起专业创作模式
- 💬 **AI 对话创作面板** — 流式续写、参考小说导入仿写、多智能体分析、选中文本润色/改写/扩写/缩写
- 👥 **角色 & 世界观管理** — 结构化角色卡、势力/规则/地理设定
- 🕘 **章节版本回溯** — 保存自动留存历史版本（每章最近 10 个），Git 风格**左右对比**，随时恢复
- 🔍 **全文搜索 & 全书问答** — 跨章节关键词检索，基于整本书内容提问
- 📊 **写作报表 & 日更目标** — 字数统计、日更进度追踪，不被历史章节污染
- 🌗 **主题切换** — 跟随系统 / 白天 / 黑夜
- 🚀 **导入导出** — 导入参考小说（可仿写风格），导出整书 MD / TXT
- 🎯 **大纲 → 细纲 → 正文** 一条龙 — 从卷级大纲到章节正文一键生成

## 🚀 快速开始

### 环境要求

- Node.js 16.14+（推荐 18 / 20）
- Rust 与系统编译工具链（构建 Tauri 桌面应用需要）
- 支持 macOS / Windows / Linux

### 开发调试

```bash
# 安装依赖
npm install

# 仅前端（浏览器调试）
npm run dev

# 启动桌面应用（Tauri）
npx tauri dev

# 运行单元测试
npm run test
```

### 构建打包

```bash
# 前端类型检查 + 构建
npm run build

# 打包桌面安装包（生成 .dmg / .msi / .AppImage 等）
npx tauri build
```

> 提示：若 `git push` 遇到 `RPC failed; HTTP 400 curl 22`，可先执行
> `git config http.version HTTP/1.1` 再推送。

## 🤖 模型配置

- **默认支持 DeepSeek**：内置官方接口地址，在「设置 → 模型配置」填入 API Key 即可使用
- **任意 OpenAI 兼容接口**：可自定义 baseURL、模型名、temperature、max_tokens、上下文携带章节数等
- 内置连通性测试，保存前可一键验证

## 🛠️ 技术栈

- **桌面框架**：Tauri 2.0（Rust）
- **前端**：Vue 3.5 + TypeScript + Vite 6
- **UI**：Element Plus 2.9 + TailwindCSS + Iconify（lucide）
- **编辑器**：Milkdown 7（Markdown 所见即所得）
- **状态管理**：Pinia 2.3
- **AI 协议**：OpenAI 兼容（流式输出）
- **测试**：Vitest + jsdom

## 🔒 数据与隐私

- 所有小说数据、角色、世界观、AI 对话记录均保存在**本地磁盘**，不经第三方服务器
- 仅在发起请求时，正文 / 指令才会发送到你配置的模型接口
- 支持自定义存储位置，可整体迁移项目
