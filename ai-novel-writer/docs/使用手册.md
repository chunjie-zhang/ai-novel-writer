## 一、软件简介

这是一款**纯本地桌面端 AI 长篇小说创作工具**，对标 FeelFish。核心特点：

- **本地存储**：所有稿件、人设、世界观、记忆、配置全部保存在本地文件夹，不上云、不泄露。
- **AI 写作**：内置 DeepSeek 官方接口预设，也可接入任意 OpenAI 兼容模型（GPT、通义、Claude、本地模型等）。
- **长篇工程化**：章节、角色、世界观、大纲、伏笔、记忆等结构化管理，面向百万字长篇。

技术栈：Tauri 2.0 + Vue 3 + Rust，前端 UI 为 Element Plus + TailwindCSS，编辑器为 Milkdown（Markdown 所见即所得）。

## 二、安装与启动

### 环境要求

- Node.js 18+（建议使用项目约定版本）
- Rust 工具链（含 Cargo）
- macOS / Windows / Linux（Tauri 支持跨平台）

### 开发模式启动

```bash
cd ai-novel-writer
npm install
npm run tauri dev
```

> 注意：如果 `npm run tauri` 报 `Missing script`，可直接用 `npx tauri dev` 或 `./node_modules/.bin/tauri dev` 启动。
> 首次启动会编译 Rust，耗时约 1-2 分钟。

### 构建正式安装包

```bash
npm run tauri build
```

## 三、界面布局总览

打开软件后，整体分四大区域：

```
┌────────────────────────────────────────────────────────────┐
│ 顶部标题栏：应用名 | 当前项目名 | [＋新建项目] [⚙设置]      │
├───────────┬──────────────────────────────┬─────────────────┤
│ 左侧：项目树 │       中间：Markdown 编辑器      │  右侧：AI 对话面板 │
│ · 项目列表    │ · 工具栏（保存/章节/专注/⋯）   │ · 聊天消息流       │
│ · 章节列表    │ · 写作区                      │ · 输入框 + 发送    │
│ · 角色/世界观 │ · 字数统计/日更目标           │ · 技能选择/导入参考 │
│ · 大纲/备份等 │                              │                  │
└───────────┴──────────────────────────────┴─────────────────┘
```

- **左侧**：项目树 + 各项目下的章节、角色管理、世界观设定、写作报表、伏笔管理、全文搜索、全书问答、小说信息、题材模板等入口。
- **中间**：主编辑器（无项目时显示欢迎页，有项目时显示工具栏 + 写作区）。
- **右侧**：AI 对话创作面板，始终可见。
- **顶部**：新建项目、设置入口；当前项目名称。

左侧和右侧面板之间都有**拖拽分隔条**，可以调整面板宽度。

## 四、快速上手：5 分钟写出第一章

1. **新建项目**：点顶部标题栏的「＋」按钮，或左侧「项目列表」顶部的「＋」按钮，或中间欢迎页的「新建小说项目」按钮。输入作品名称（可填简介、选择存储位置），点「创建项目」。
2. **配置模型（可选）**：点顶部「⚙设置」→「模型配置」，填入 DeepSeek API Key（见第九节），点「保存配置」。不配置也可体验界面，但 AI 功能不可用。
3. **新建章节**：点中间工具栏的「章节」按钮，输入章节名，点「创建」。
4. **开始写作**：在编辑器里直接输入内容；右上角会显示「本章 字数」和「未保存/已保存」状态。
5. **AI 续写**：在右侧 AI 面板输入框输入需求（如「续写当前章节」），点「发送」。生成完成后，AI 回复下方有「保存为章节」「保存为角色」按钮。
6. **保存**：点工具栏「保存」按钮，或按 `Ctrl+S`（Mac 为 `Cmd+S`）。

## 五、项目管理

### 5.1 新建项目 ✅

- **入口**：顶部标题栏「＋」按钮 ｜ 左侧项目列表顶部「＋」按钮 ｜ 欢迎页「新建小说项目」按钮。
- **操作**：填写作品名称（必填）、简介（可选）、存储位置（可选，不选则用默认目录），点「创建项目」。

### 5.2 打开 / 切换项目 ✅

- **入口**：左侧「项目列表」中点击某个项目名，展开章节树即打开该项目。
- 顶部标题栏会显示当前项目名。

### 5.3 删除项目 ✅

- **入口**：左侧项目节点右侧的 🗑 图标按钮。
- **操作**：点击后确认删除。会同时删除该项目的 AI 对话记录。

### 5.4 重命名 / 编辑小说信息 ✅

- **入口**：左侧项目树中「小说信息」菜单项（在章节列表下方）。
- **操作**：可修改作品名称、笔名/作者、题材、状态、简介、标签、封面。

### 5.5 迁移单个项目到新位置 ⚠️

- **入口**：左侧项目节点右侧的 📥（文件夹输入）图标按钮。
- **说明**：可把单个项目迁到指定目录。注意：迁移后文件夹会以 UUID 命名（见第十三节已知问题）。

### 5.6 全局存储路径 / 批量迁移 ⚠️

- **入口**：顶部「⚙设置」→「存储位置」标签页。
- **说明**：
  - 「更改」按钮：直接切换全局存储路径。⚠️ 有丢失现有项目列表的风险（见第十三节），建议优先用「迁移到新位置」。
  - 「迁移到新位置」按钮：把当前存储位置的所有项目整体迁移到新目录，安全。

## 六、编辑器与写作

### 6.1 新建章节 ✅

- **入口**：工具栏「章节」按钮；或编辑器空态时「新建章节」按钮。
- **操作**：输入章节名创建；章节名支持「分组/章名」格式（如 `第一卷/第1章 初入江湖`）实现分组。

### 6.2 保存章节 ✅

- **入口**：工具栏「保存」按钮（内容修改后变为可用）；快捷键 `Ctrl+S` / `Cmd+S`。
- 顶部有保存状态提示：「已保存 / 未保存 / 保存中」。

> ⚠️ 说明：目前**没有真正的定时自动保存到磁盘**。只有「断稿记忆」会在本地暂存未保存内容（见 6.4），建议养成手动保存习惯。

### 6.3 字数统计与日更目标 ⚠️

- **入口**：工具栏「本章 xxx 字」显示本章字数；旁边「今日 x/xxx (xx%)」显示日更进度。
- **设置日更目标**：点击「今日 …」文字，弹出对话框设置每日目标字数。
- ⚠️ 已知问题：切换章节/打开章节时，历史章节字数会被误计入「今日已写」，导致统计偏大（见第十三节）。

### 6.4 断稿记忆 ⚠️

- **说明**：编辑内容每变化 3 秒自动暂存到本地（localStorage），下次打开章节时可恢复。
- ⚠️ 已知问题：目前只暂存内容；**光标位置、滚动位置的回溯未生效**（始终从开头开始），且暂存记忆不区分项目（见第十三节）。

### 6.5 专注码字模式 ✅

- **入口**：工具栏右下角的全屏展开图标按钮（`⤢`）。
- **操作**：点击进入全屏专注模式，再点一次退出。仅 UI 全屏，无防误切页面。

### 6.6 选中文本 AI 快捷操作 ❌

- **入口**：本应在编辑器选中文字后弹出的浮动工具条（润色 / 改写 / 扩写 / 缩写）。
- **状态**：❌ **当前不可用**。选中文字不会弹出工具条，功能未生效（见第十三节）。

## 七、更多工具（编辑器右上角 ⋯ 菜单）

点击编辑器工具栏最右侧的「⋯」按钮，弹出下拉菜单，包含以下功能：

| 菜单项 | 功能说明 | 状态 |
|--------|---------|------|
| 文风采样 | 采集当前文本风格，供 AI 后续模仿 | ❌ 不可用（点击无反应） |
| 排版规整 | 规整段落空行、首行缩进等排版 | ✅ 可用 |
| AI 校对（错别字/语病） | 检查错别字、语病并提示 | ✅ 可用 |
| 敏感词检查 | 检测并替换敏感词 | ⚠️ 有误报（见 7.3） |
| 剧情节奏检测 | 本地算法分析本章节奏，弹出报告 | ✅ 可用 |
| 去重检测 / 水文优化 | 检测重复内容/水文，可一键去重 | ✅ 可用 |
| 章节批量管理 | 批量改名、排序、删除、导出章节 | ⚠️ 有缺陷（见 7.4） |
| 导出 Markdown | 整本书导出为 .md 文件 | ✅ 可用 |
| 导出 TXT | 整本书导出为 .txt 文件 | ✅ 可用 |
| Diff 增量改写 | AI 对本章做增量改写，左右对照 | ⚠️ 只能整章改写 |
| 大纲→细纲生成 | 根据当前大纲生成细纲 | ✅ 可用 |
| 多智能体分析 | 多视角 AI 分析本章 | ⚠️ 会污染聊天记录 |

### 7.1 排版规整 ✅

- **入口**：⋯ 菜单 →「排版规整」。
- 对当前章节正文做本地排版处理。

### 7.2 AI 校对 ✅

- **入口**：⋯ 菜单 →「AI 校对（错别字/语病）」。
- 结合本地词库 + AI 对当前章节检查错别字、语病，弹出结果并可应用修正。

### 7.3 敏感词检查 ⚠️

- **入口**：⋯ 菜单 →「敏感词检查」。
- ⚠️ 已知问题：内置词表包含**单字**词（如「习」），会把「学习、习惯」等正常词误判并替换成 `***`，可能破坏正文。建议谨慎使用「一键替换」。

### 7.4 章节批量管理 ⚠️

- **入口**：⋯ 菜单 →「章节批量管理」。
- 支持：批量改名、排序（上移/下移）、删除、导出。
- ⚠️ 已知问题：批量改名会丢失分组前缀（分组章节被移到根目录）；排序可能残留临时空目录（见第十三节）。

### 7.5 导出 Markdown / TXT ✅

- **入口**：⋯ 菜单 →「导出 Markdown」或「导出 TXT」。
- 整本书按章节顺序导出为一个文件并触发下载。

### 7.6 Diff 增量改写 ⚠️

- **入口**：⋯ 菜单 →「Diff 增量改写」。
- 弹出对话框，AI 改写当前章节，左右两栏对照原文与改写结果。
- ⚠️ 已知问题：无法针对选中的文字改写（总是处理整章）；且没有真正的差异高亮。

### 7.7 大纲→细纲生成 ✅

- **入口**：⋯ 菜单 →「大纲→细纲生成」。
- 读取当前大纲，调用 AI 生成细纲（会写入右侧对话）。

### 7.8 多智能体分析 ⚠️

- **入口**：⋯ 菜单 →「多智能体分析」。
- 同时以多个身份（如编辑、读者、逻辑检查）分析当前章节。
- ⚠️ 已知问题：结果会作为多条消息写入右侧 AI 对话并持久化，刷屏聊天记录。

## 八、AI 对话创作面板

位于窗口右侧，始终可用。顶部有三个小按钮：

### 8.1 导入参考小说 ✅

- **入口**：AI 面板顶部「⬆」（上传）按钮。
- **操作**：选择本地 .md/.txt 小说文件导入为参考。导入后可让 AI 参考其文风/世界观创作。
- 导入后顶部出现参考小说状态栏：显示书名、章节数，可切换「写作模式」（仿写风格），点 × 移除。

### 8.2 写作技能选择 ✅

- **入口**：AI 面板顶部「✨」（sparkles）按钮。
- **操作**：展开技能列表，选择一个写作技能（如写大纲、写人设、改剧情、填坑、纠错），此后 AI 按该技能工作；可「取消」当前技能。
- ⚠️ 说明：技能「启用/禁用」开关暂未接入界面，仅支持单选一个技能。

### 8.3 清空对话 ✅

- **入口**：AI 面板顶部「🗑」按钮。
- 清空当前项目的 AI 对话记录。

### 8.4 快捷创作建议 ✅

- 空对话时，输入框上方有建议标签：「帮我写一个大纲」「生成一个人物设定」「续写当前章节」「检查剧情漏洞」，点击即可快速发起。

### 8.5 发送与流式输出 ✅

- 在输入框输入需求，点「发送」或 `Ctrl+Enter`。
- 采用流式输出，AI 逐字生成。生成中显示「思考中…」动画，输入框禁用。

### 8.6 保存 AI 回复 ✅

AI 每条回复下方有两个按钮：

- **保存为章节**：把该回复内容保存为一个新章节（支持分组、自动防重名）。
- **保存为角色**：把回复解析为角色档案并加入角色库（支持 JSON / 文本格式解析）。

### 8.7 自动能力（后台触发）⚠️

- **人设 OOC 校验**：发送消息后自动触发，检测角色是否脱离人设。⚠️ 校验结果会作为两条消息写入对话，刷屏并持久化历史。
- **情绪适配**：根据当前章节情绪自动调整生成温度。⚠️ 会覆盖你在「写作场景预设」里选定的温度，导致场景参数失效。

## 九、模型与参数设置

**入口**：顶部「⚙设置」→「模型配置」标签页。

### 9.1 模型来源 ✅

- **DeepSeek 官方**（默认）：已预设接口地址与模型名，**需自行填写 API Key**。
  - 模型版本二选一：`DeepSeek V4 Flash ⚡`（快速创作） / `DeepSeek V4 Pro 🧠`（深度推理）。
- **自定义模型**：选择后可填写 Base URL、API Key、模型名称，适配 GPT、通义千问、Claude、本地私有模型等任意 OpenAI 兼容接口。

### 9.2 写作场景预设 ✅

六个场景卡片，一键切换生成参数：

| 场景 | 适用 |
|------|------|
| ⚡ 快速续写 | 延续剧情快速输出 |
| ✨ 精细润色 | 优化文笔措辞 |
| 💡 剧情构思 | 创意发散、拓展方向 |
| 👤 人设生成 | 生成立体角色设定 |
| 🔍 逻辑纠错 | 检查剧情漏洞、逻辑矛盾 |
| 📋 大纲优化 | 梳理优化大纲结构 |

### 9.3 生成参数 ✅

- **创意度 (Temperature)**：滑杆调节，0-2。较低更确定、较高更有创意。
- **最大生成长度**：数字调节，默认 4096。

### 9.4 记忆设置 ⚠️

- **携带章节数**：设置续写时携带最近 N 章的 AI 摘要作为上下文（默认 10）。
- ⚠️ 已知问题：该参数当前**未真正生效**（未接入请求逻辑），且「章节记忆摘要」本身尚未接入（见第十三节）。

### 9.5 测试连接 / 保存配置 ✅

- **测试连接**：校验 API Key 是否可用。
- **保存配置**：保存模型设置（本地存储 + 磁盘）。

> 右侧面板底部会显示当前生效模型与 Key 状态（如「未填写 API Key」）。

## 十、左侧项目树功能面板

在左侧「项目列表」标题右侧有三个图标按钮：**大纲管理（🌳）｜ 备份管理（💾）｜ 新建项目（＋）**。

打开项目后，章节列表下方依次是以下功能入口（点击打开对应弹窗/面板）：

### 10.1 大纲管理 ⚠️

- **入口**：左侧「项目列表」标题旁的 🌳（大纲管理）按钮。
- 三级大纲（卷 → 章）管理：可新增/编辑/删除卷与章，支持拖动调整顺序。
- ⚠️ 已知问题：大纲数据为**全局存储，不区分项目**，切换小说会串数据（见第十三节）。

### 10.2 备份管理 ⚠️

- **入口**：左侧「项目列表」标题旁的 💾（备份管理）按钮。
- 支持：创建备份、恢复备份、删除备份。
- ⚠️ 已知问题：备份列表为**全局共享**，任意项目都能看到所有小说的备份，恢复时可能把别的书覆盖到当前项目（见第十三节）。恢复前请仔细核对。

### 10.3 角色管理 ✅

- **入口**：项目树章节列表下方「角色管理」。
- 操作：查看/新增/编辑/删除角色；空列表时有「AI 一键生成角色」按钮。
- 角色字段：姓名、身份、性格、目标、能力、弱点、背景等（具体以界面为准）。

### 10.4 世界观设定 ✅

- **入口**：项目树「世界观设定」。
- 操作：编辑世界观描述、地理、势力、规则、地图等，保存后写入项目。

### 10.5 写作报表 ⚠️

- **入口**：项目树「写作报表」。
- 展示周历写作情况、日均字数、章节字数统计等。
- ⚠️ 已知问题：因字数统计被「打开章节」污染（见 6.3），报表数据可能失真。

### 10.7 全文搜索 ✅

## 十三、已知问题与限制

### 🔴 高优先级（功能不可用）

1. **选中文本 AI 操作不可用**：编辑器选中文字后不会弹出「润色/改写/扩写/缩写」浮栏，相关操作与「文风采样」均无反应。原因：浮栏显示开关从未更新、代码读取了不存在的 `.editor-textarea` 元素。
2. **切换章节后编辑器可能不刷新**：点击左侧其他章节时，中间编辑器可能仍显示旧章节内容（外部内容同步失效）。遇到请重启章节或保存重开。
3. **断稿记忆光标回溯无效**：只能暂存内容，光标/滚动位置始终从零开始，且记忆不区分项目。
4. **章节记忆摘要（AI 长篇记忆库）未接入**：方案核心的「章节记忆摘要」无任何入口，`memory.json` 从不写入，长篇连贯记忆能力为空。

### 🟡 中优先级（数据错误/丢失风险）

5. **字数统计被污染**：打开历史章节时，章节字数差被误计入「今日已写/累计」，导致日更目标与写作报表失真。
6. **备份全局共享**：任意项目都能看到所有小说的备份，恢复时可能把别的书覆盖到当前项目。
7. **敏感词单字误报**：内置词表含单字词，会把「学习、习惯」等误判并替换成 `***`，可能破坏正文。
8. **大纲/伏笔全局存储**：切换小说会串数据，与「每本小说独立存储」的设计不符。

### 🟢 低优先级 / 功能缺口

9. **无定时自动保存**：只有手动保存 + 断稿暂存，建议尽快补自动写盘。
10. **单项目独立绑定模型未实现**：项目级模型配置未接入前端。
11. **无章节历史版本回溯**：只有整项目快照备份，无章节级版本管理。
12. **无细纲→正文一键生成**：目前只有「大纲→细纲」。
13. **内置 DeepSeek 仍需填 Key**：与方案「零配置开箱即用」不符，但属预期（官方接口需 Key）。
