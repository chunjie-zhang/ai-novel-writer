# AI小说桌面端创作工具（对标FeelFish）项目方案【终版可开发】

## 一、项目概述

本项目是一款**纯本地桌面端AI长篇小说创作工具**，对标 FeelFish、彩云小梦、墨咕AI 等主流付费工具，聚焦网文作者核心痛点：大模型续写失忆、人设OOC、剧情矛盾、文风割裂、长篇连载难以管控。

软件基于 Tauri2 \+ Vue3 \+ Rust 开发，**所有稿件、人设、记忆、配置全部本地存储**，不上云、不泄露、无需担心扣费与稿件丢失。

模型策略采用双引擎方案：**内置 DeepSeek 开箱即用 \+ 用户自定义全量 OpenAI 兼容模型**，一键切换，适配小白用户与高阶专业用户。

## 二、产品核心定位（区别普通AI聊天工具）

- 不是通用AI对话工具，是**结构化长篇小说工程管理系统**

- 拥有小说专属**记忆库\+人设库\+世界观库**，保障百万字长篇剧情连贯

- AI可读写、可增量修改书稿，实现对话即创作

- 全项目文件化管理，可备份、可迁移、可离线使用

## 三、最终确定技术栈

- **桌面端框架**：Tauri 2\.0（轻量、无冗余、跨平台、本地文件高权限）

- **前端框架**：Vue3 \+ TypeScript \+ Vite

- **UI框架**：Element Plus \+ TailwindCSS

- **编辑器**：Milkdown Markdown 专业小说编辑器

- **底层能力**：Rust（文件管理、SSE流式转发、本地算法调度、配置持久化）

- **AI协议**：标准 OpenAI 通用兼容协议

- **本地智能算法**：NPM NLP开源包（语义召回、情绪识别、关键词提取、文本差分）

## 四、AI模型架构（核心定稿）

### 1\. 双模型运行模式

**模式A：内置 DeepSeek（零配置开箱即用）**

- 软件内置官方接口地址与默认模型名，用户无需填写Key

- 默认启用 deepseek\-chat 写作模型，适配网文叙事、续写、润色场景

- 面向小白用户、快速创作、日常连载

**模式B：用户自定义模型（全开放可配置）**

用户可自主填写 API Key、Base URL、模型名称，可适配 GPT、通义千问、Claude、本地私有化模型等所有OpenAI兼容接口。

### 2\. 全局可配置参数

所有模型统一支持：temperature、top\_p、max\_tokens、上下文记忆条数、流式输出开关。

### 3\. 模型优先级规则（固定）

- 用户配置自定义模型 → 优先使用用户模型

- 无自定义配置 → 自动 fallback 内置 DeepSeek

- 支持**单小说项目独立绑定模型**，不同题材可切换不同模型创作

## 五、项目文件结构（本地工程化管理）

每本小说独立项目文件夹，完全隔离数据，结构固定：

```Plain Text
/project
  /chapters      # 所有章节md原稿
  character.json # 角色人设档案库
  world.md       # 世界观、势力、规则、地图设定
  memory.json    # 章节摘要记忆库（长篇连贯核心）
  config.json    # 项目独立模型配置

```
