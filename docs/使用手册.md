## 一、软件简介

这是一款**纯本地桌面端 AI 长篇小说创作工具**，对标 FeelFish。核心特点：

- **本地存储**：所有稿件、人设、世界观、记忆、配置全部保存在本地文件夹，不上云、不泄露。
- **AI 写作**：内置 DeepSeek 官方接口预设，也可接入任意 OpenAI 兼容模型（GPT、通义、Claude、本地模型等）。
- **长篇工程化**：章节、角色、世界观、大纲、伏笔、记忆等结构化管理，面向百万字长篇。

技术栈：Tauri 2.0 + Vue 3 + Rust，前端 UI 为 Element Plus + TailwindCSS，编辑器为 Milkdown（Markdown 所见即所得）。

## 二、安装与启动

### 环境要求

- Node.js 18+（建议使用项目约定版本）
- Rust 工具链（含 Cargo）
- macOS / Windows / Linux（Tauri 支持跨平台）

### 开发模式启动

```bash
cd ai-novel-writer
npm install
npm run tauri dev
```

> 注意：如果 `npm run tauri` 报 `Missing script`，可直接用 `npx tauri dev` 或 `./node_modules/.bin/tauri dev` 启动。
> 首次启动会编译 Rust，耗时约 1-2 分钟。

### 构建正式安装包

```bash
npm run tauri build
```

## 三、界面布局总览

打开软件后，整体分四大区域：

```
┌────────────────────────────────────────────────────────────┐
│ 顶部标题栏：应用名 | 当前项目名 | [＋新建项目] [⚙设置]      │
├───────────┬──────────────────────────────┬─────────────────┤
│ 左侧：项目树 │       中间：Markdown 编辑器      │  右侧：AI 对话面板 │
│ · 项目列表    │ · 工具栏（保存/章节/专注/⋯）   │ · 聊天消息流       │
│ · 章节列表    │ · 写作区                      │ · 输入框 + 发送    │
│ · 角色/世界观 │ · 字数统计/日更目标           │ · 技能选择/导入参考 │
│ · 大纲/备份等 │                              │                  │
└───────────┴──────────────────────────────┴─────────────────┘
```

- **左侧**：项目树。每个项目展开后：**「小说功能」折叠分组在顶部**（角色管理、世界观设定、写作报表、伏笔管理、全文搜索、全书问答、小说信息、题材模板，点击展开）；下方是**「📁 章节」收纳文件夹**（显示章节总数，如 `章节 5章`），点开才显示章节列表（按「第一卷/第二卷」等分组排列）——这样即使小说有上千章，也收纳在「章节」文件夹里，不会平铺散开，「小说功能」也始终可见（2026-08-10 重构）。
- **中间**：主编辑器（无项目时显示欢迎页，有项目时显示工具栏 + 写作区）。
- **右侧**：AI 对话创作面板，始终可见。
- **顶部**：新建项目、设置入口；当前项目名称。

左侧和右侧面板之间都有**拖拽分隔条**，可以调整面板宽度。

## 四、快速上手：5 分钟写出第一章

### 0. 新手引导 + 示例项目（强烈推荐）

- **首次启动**会自动弹出「新手引导」，分 6 步介绍界面布局、编辑器、AI 创作、小说功能等入口与用途；也可随时点顶部 **「?」按钮**再次打开。
- **一键创建示例项目**：在引导最后一步点「一键创建示例项目」，会生成一个带示例数据的项目「示例小说·星辰之旅」（含 3 个示例章节、3 个示例角色、完整世界观），边看边玩最快上手。
- 示例项目和你自己创建的项目完全一样，可随意修改；不需要时在左侧项目节点点 **🗑** 即可删除。
- 引导完成后不会每次启动都弹出（自动记住）。

### 1. 新建项目

点顶部标题栏的「＋」按钮，或左侧「项目列表」顶部的「＋」按钮，或中间欢迎页的「新建小说项目」按钮。输入作品名称（可填简介、选择存储位置），点「创建项目」。

### 2. 配置模型（可选）

点顶部「⚙设置」→「模型配置」，填入 DeepSeek API Key（见第九节），点「保存配置」。不配置也可体验界面，但 AI 功能不可用。

### 3. 新建章节

点中间工具栏的「章节」按钮，输入章节名，点「创建」。

### 4. 开始写作

在编辑器里直接输入内容；右上角会显示「本章 字数」和「未保存/已保存」状态。

### 5. AI 续写

在右侧 AI 面板输入框输入需求（如「续写当前章节」），点「发送」。生成完成后，AI 回复下方有「保存为章节」「保存为角色」按钮。

### 6. 保存

点工具栏「保存」按钮，或按 `Ctrl+S`（Mac 为 `Cmd+S`）。

## 五、项目管理

### 5.1 新建项目 ✅

- **入口**：顶部标题栏「＋」按钮 ｜ 左侧项目列表顶部「＋」按钮 ｜ 欢迎页「新建小说项目」按钮。
- **操作**：填写作品名称（必填）、简介（可选）、存储位置（可选，不选则用默认目录），点「创建项目」。

### 5.2 打开 / 切换项目 ✅

- **入口**：左侧「项目列表」中点击某个项目名，展开章节树即打开该项目。
- 顶部标题栏会显示当前项目名。

### 5.3 删除项目 ✅

- **入口**：左侧项目节点右侧的 🗑 图标按钮。
- **操作**：点击后确认删除。会同时删除该项目的 AI 对话记录。

### 5.4 重命名 / 编辑小说信息 ✅

- **入口**：左侧项目树中「小说信息」菜单项（在章节列表下方）。
- **操作**：可修改作品名称、笔名/作者、题材、状态、简介、标签、封面。

### 5.5 迁移单个项目到新位置 ⚠️

- **入口**：左侧项目节点右侧的 📥（文件夹输入）图标按钮。
- **说明**：可把单个项目迁到指定目录。注意：迁移后文件夹会以 UUID 命名（见第十三节已知问题）。

### 5.6 全局存储路径 / 批量迁移 ⚠️

- **入口**：顶部「⚙设置」→「存储位置」标签页。
- **说明**：
  - 「更改」按钮：直接切换全局存储路径。⚠️ 有丢失现有项目列表的风险（见第十三节），建议优先用「迁移到新位置」。
  - 「迁移到新位置」按钮：把当前存储位置的所有项目整体迁移到新目录，安全。

## 六、编辑器与写作

> ✅ **已修复（2026-08-07）**：此前「Markdown 编辑器无法渲染」的问题已修复——把 `<MilkdownProvider>` 移到使用 `useEditor` 的内容组件外层，编辑器现在可正常显示章节、编辑与切换章节。

### 6.1 新建章节 ✅

- **入口**：工具栏「章节」按钮；或编辑器空态时「新建章节」按钮。
- **新建卷（2026-08-10 新增）**：左侧「📁 章节」文件夹标题右侧的「＋」按钮，输入卷名（默认自动按序排「第N卷」）即可创建一个空卷；空卷会显示在「章节」文件夹里，之后可往卷里新建章节。
- **删除章节 / 删除卷（2026-08-10 新增）**：鼠标悬停在章节或卷分组上，右侧出现垃圾桶按钮——删除章节只删该章；删除卷会**连同卷内所有章节**一起删除（有二次确认，提示卷内章节数）。删除同时清理对应章节的历史版本。
- **操作**：输入章节名创建（如 `第1章 天启城`）。
- **自动编号（2026-08-10 新增）**：打开「新建章节」时，章节名会自动预填**下一个全局章节号**（如已有第 1~3 章则预填「第4章 」）。编号按**整本小说全局递增**，不会因为切到第二卷就从第 1 章重新开始；你只需在编号后继续输入标题，也可自行修改。
- **分组（2026-08-10 新增）**：两种方式把章节放进分组（如「第一卷」）：
  1. 在「分组」下拉里选择已有分组，或直接输入新分组名（留空则放到根目录）；
  2. 或直接在章节名里写「分组/章节名」，如 `第一卷/第1章 天启城`，自动拆分到「第一卷」分组。
  - 左侧「📁 章节」文件夹展开后，会按「第一卷 / 第二卷…」分组展示。
- 创建成功后左侧章节列表会**立即刷新**显示新章节（2026-08-10 修复）。
- 编辑器内按回车可正常换行分段（2026-08-10 修复）。

### 6.2 保存章节 ✅

- **自动保存（2026-08-10 新增）**：编辑内容后停止输入 **3 秒**，会自动写入磁盘并留存历史版本，无需手动点保存。
- **手动保存**：工具栏「保存」按钮（内容修改后变为可用）；快捷键 `Ctrl+S` / `Cmd+S`。
- 顶部有保存状态提示：「已保存 / 未保存 / 保存中」——自动保存成功后状态会自动回到「已保存」。
- 自动保存与手动保存走同一套逻辑：都会更新字数、留存章节历史版本，并在首行标题变化时同步重命名（见 6.3）。

> ✅ 说明：此前「无定时自动保存」的限制已在 2026-08-10 解决；断稿记忆（见 6.5）仍保留作为兜底。

### 6.3 修改章节标题 ✅（2026-08-10 新增）

- **入口**：编辑器**顶部固定的标题栏**（`第N章` + 标题输入框）——标题栏始终固定在编辑器顶部，正文在下方独立滚动。
- **操作**：直接在标题栏输入框修改标题（如「天启城」→「天启新城」），改完失焦/回车即生效：自动写入正文首行、触发保存，左侧目录同步更新、文件名同步重命名（保留分组）、历史版本一并迁移。
- 标题自动规范化：若历史数据首行带分组路径（如 `# 第一卷/第1章 天.md`），打开章节时会自动清理成纯标题（2026-08-10 修复）。
- 若章节无「第N章」前缀，标题栏只显示输入框。

### 6.4 字数统计与日更目标 ⚠️

- **入口**：工具栏「本章 xxx 字」显示本章字数；旁边「今日 x/xxx (xx%)」显示日更进度。
- **设置日更目标**：点击「今日 …」文字，弹出对话框设置每日目标字数。
- ⚠️ 已知问题：切换章节/打开章节时，历史章节字数会被误计入「今日已写」，导致统计偏大（见第十三节）。

### 6.5 断稿记忆 ⚠️

- **说明**：编辑内容每变化 3 秒自动暂存到本地（localStorage），下次打开章节时可恢复。在自动保存（6.2）基础上再提供一层防丢失保障。
- ⚠️ 已知问题：目前只暂存内容；**光标位置、滚动位置的回溯未生效**（始终从开头开始），且暂存记忆不区分项目（见第十三节）。

### 6.6 专注码字模式 ✅

- **入口**：工具栏右下角的全屏展开图标按钮（`⤢`）。
- **操作**：点击进入全屏专注模式，再点一次退出。仅 UI 全屏，无防误切页面。

### 6.7 选中文本 AI 快捷操作 ✅

- **入口**：在编辑器正文中**选中一段文字**，上方会自动弹出浮动工具条（润色 / 改写 / 扩写 / 缩写）。
- **操作**：点击对应按钮，AI 会对选中文字做处理，并用结果替换选中区域（不覆盖整章）。
- ✅ 已修复（2026-08-07）：改用 Milkdown/ProseMirror 选区能力 + 选区缓存，浮栏可正常出现，操作可正常生效。

## 七、更多工具（编辑器右上角 ⋯ 菜单）

点击编辑器工具栏最右侧的「⋯」按钮，弹出下拉菜单，包含以下功能：

| 菜单项 | 功能说明 | 状态 |
|--------|---------|------|
| 文风采样 | 采集当前文本风格，供 AI 后续模仿 | ❌ 不可用（点击无反应） |
| 排版规整 | 规整段落空行、首行缩进等排版 | ✅ 可用 |
| AI 校对（错别字/语病） | 检查错别字、语病并提示 | ✅ 可用 |
| 敏感词检查 | 检测并替换敏感词 | ⚠️ 有误报（见 7.3） |
| 剧情节奏检测 | 本地算法分析本章节奏，弹出报告 | ✅ 可用 |
| 去重检测 / 水文优化 | 检测重复内容/水文，可一键去重 | ✅ 可用 |
| 章节批量管理 | 批量改名、排序、删除、导出章节 | ⚠️ 有缺陷（见 7.4） |
| 导出 Markdown | 整本书导出为 .md 文件 | ✅ 可用 |
| 导出 TXT | 整本书导出为 .txt 文件 | ✅ 可用 |
| Diff 增量改写 | AI 对本章做增量改写，左右对照 | ⚠️ 只能整章改写 |
| 大纲→细纲生成 | 根据当前大纲生成细纲 | ✅ 可用 |
| 细纲→正文生成 | 根据细纲一键生成章节正文 | ✅ 可用（2026-08-10 新增） |
| 章节版本回溯 | 保存时自动留存章节历史版本，可回看/恢复 | ✅ 可用（2026-08-10 新增） |
| 多智能体分析 | 多视角 AI 分析本章 | ⚠️ 会污染聊天记录 |

### 7.1 排版规整 ✅

- **入口**：⋯ 菜单 →「排版规整」。
- 对当前章节正文做本地排版处理。

### 7.2 AI 校对 ✅

- **入口**：⋯ 菜单 →「AI 校对（错别字/语病）」。
- 结合本地词库 + AI 对当前章节检查错别字、语病，弹出结果并可应用修正。

### 7.3 敏感词检查 ⚠️

- **入口**：⋯ 菜单 →「敏感词检查」。
- ⚠️ 已知问题：内置词表包含**单字**词（如「习」），会把「学习、习惯」等正常词误判并替换成 `***`，可能破坏正文。建议谨慎使用「一键替换」。

### 7.4 章节批量管理 ⚠️

- **入口**：⋯ 菜单 →「章节批量管理」。
- 支持：批量改名、排序（上移/下移）、删除、导出。
- ⚠️ 已知问题：批量改名会丢失分组前缀（分组章节被移到根目录）；排序可能残留临时空目录（见第十三节）。

### 7.5 导出 Markdown / TXT ✅

- **入口**：⋯ 菜单 →「导出 Markdown」或「导出 TXT」。
- 整本书按章节顺序导出为一个文件并触发下载。

### 7.6 Diff 增量改写 ⚠️

- **入口**：⋯ 菜单 →「Diff 增量改写」。
- 弹出对话框，AI 改写当前章节，左右两栏对照原文与改写结果。
- ⚠️ 已知问题：无法针对选中的文字改写（总是处理整章）；且没有真正的差异高亮。

### 7.7 大纲→细纲生成 ✅

- **入口**：⋯ 菜单 →「大纲→细纲生成」。
- 读取当前大纲，调用 AI 生成细纲（会写入右侧对话）。

### 7.8 细纲→正文一键生成 ✅（2026-08-10 新增）

- **入口**：⋯ 菜单 →「细纲→正文生成」。
- 弹出对话框：
  1. 输入章节细纲（点「从当前章节内容导入」可把当前正文前 2000 字填入，也可手动粘贴）；
  2. 设置目标字数、风格/额外要求；
  3. 点「生成正文」，AI 按细纲扩写成完整章节正文；
  4. 生成后可选择「替换章节内容」「追加到章节末尾」「插入到光标处」三种方式应用（替换前自动留存当前内容为历史版本，可回退）。
- 配合「大纲→细纲生成」使用：先由大纲生成细纲，再由此功能把细纲扩写为正文。

### 7.9 章节版本回溯 ✅（2026-08-10 新增）

- **入口**：⋯ 菜单 →「章节版本回溯」。
- 每次**保存章节**时，系统自动留存一份历史快照（每章保留最近 10 个版本）。
- **左右分栏交互**（2026-08-10 优化）：左侧是版本列表（时间 / 字数 / 最近标记），点击某个版本，右侧立即显示它与当前内容的**左右并排差异对比**（类似 Git diff）：
  - 左栏「📄 历史版本」、右栏「✍️ 当前内容」，对应行逐行对齐；
  - 差异高亮：该版本有而当前没有的行 → 左栏**红色删除线**；当前有而该版本没有的行 → 右栏**绿色新增**；相同行灰色；
  - 顶部汇总「新增 x 行 · 删除 y 行 · 相同 z 行」，一眼看清恢复该版本的影响；
  - 对比区独立滚动，**即使章节内容很长也不影响左侧浏览版本**。
  - 右侧顶部提供「恢复此版本」「删除」操作。
- 恢复前会把当前内容先存为一个新版本，保证可回退；删除章节 / 删除项目时对应版本历史一并清理。

- 同时以多个身份（如编辑、读者、逻辑检查）分析当前章节。

## 十三、已知问题与限制

### 🔴 高优先级（功能不可用）

0. **~~Markdown 编辑器完全无法渲染~~ ✅ 已修复（2026-08-07）**：原问题为 `MilkdownEditor.vue` 把 `<MilkdownProvider>` 放在组件自身模板内，而 `useEditor` 在 `<script setup>` 顶层调用，导致 `inject` 为 undefined、编辑器空白。已通过拆分「容器 + 内容」组件修复：`<MilkdownProvider>` 正确包裹使用 `useEditor` 的内容组件，并改用 `parserCtx`/`editorViewCtx` 做外部内容同步。打开章节、切换章节、编辑、保存均已实测通过。

1. **~~选中文本 AI 操作不可用~~ ✅ 已修复（2026-08-07）**：原因为浮栏开关 `hasSelection` 从未更新 + 代码依赖不存在的 `.editor-textarea` 元素（实际编辑器是 Milkdown）。已改为：通过 Milkdown 暴露的 ProseMirror 选区能力读取/替换选区，并用选区缓存解决点菜单时失焦导致选区读不到的问题。实测：选中浮栏显示、润色/改写替换选区、文风采样（选中与全文两种模式）均正常。
2. **切换章节后编辑器可能不刷新**：点击左侧其他章节时，中间编辑器可能仍显示旧章节内容（外部内容同步失效）。遇到请重启章节或保存重开。
3. **断稿记忆光标回溯无效**：只能暂存内容，光标/滚动位置始终从零开始，且记忆不区分项目。
4. **章节记忆摘要（AI 长篇记忆库）未接入**：方案核心的「章节记忆摘要」无任何入口，`memory.json` 从不写入，长篇连贯记忆能力为空。

### 🟡 中优先级（数据错误/丢失风险）

5. **~~字数统计被污染~~ ✅ 已修复（2026-08-10）**：改为监听「编辑器实际输入」的增量，打开/切换章节不再计入「今日已写/累计」，日更目标与写作报表恢复准确。
6. **~~备份全局共享~~ ✅ 已修复（2026-08-10）**：备份列表按项目过滤、恢复/删除校验归属，不会再把别的小说的备份覆盖到当前项目。
7. **~~敏感词单字误报~~ ✅ 已修复（2026-08-10）**：从词表移除单字词「习」，不再误判「学习、习惯」等正常词。
8. **~~大纲/伏笔全局存储~~ ✅ 已修复（2026-08-10）**：大纲与伏笔按项目隔离存储（key 带 projectId），切换小说不会串数据。

### 🟢 低优先级 / 功能缺口

9. **~~无定时自动保存~~ ✅ 已实现（2026-08-10）**：编辑停止 3 秒后自动写盘并留存历史版本，断稿记忆保留为兜底。
